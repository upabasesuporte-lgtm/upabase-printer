# Upabase Impressão

Programa para Windows que imprime sozinho os cupons, comandas e pedidos do **Upabase** (sistema de PDV, delivery e restaurante).

**Baixar:** [Upabase-Impressao-Setup.exe](https://github.com/upabasesuporte-lgtm/upabase-printer/releases/latest/download/Upabase-Impressao-Setup.exe)

O programa se atualiza sozinho. Este repositório guarda apenas os instaladores.

Sistema: https://www.upabase.com.br
